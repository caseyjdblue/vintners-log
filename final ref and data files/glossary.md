# Glossary — Winemaking Reference Catalogue

**Catalogue:** Glossary (Reference File 10)
**Scope of this edition:** Plain-language definitions of the terms used across the knowledge base, in one place for quick lookup and UI tooltips/search. Strain names live in Yeast Strains; specific additive products and doses live in Additives — this glossary covers the general vocabulary.
**Status:** Living document — add terms as the base grows.

---

## How to use this file

One alphabetical table. The **Detail in** column points to the catalogue where the term is used or explained in depth, so a UI can link a tooltip straight to its source.

| Term | Definition | Detail in |
|---|---|---|
| **ABV** | Alcohol by volume; estimated as (OG − FG) × 131.25. | Calculations |
| **Acetobacter / acetic (VA)** | Oxygen-loving bacteria that turn wine to vinegar; a volatile-acidity fault. | Troubleshooting B3 |
| **Acid blend** | Tartaric/malic/citric blend added to raise titratable acidity. | Additives |
| **Acid reducer** | Potassium bicarbonate (or calcium carbonate) used to lower acidity. | Additives |
| **Airlock** | One-way valve letting CO₂ out while keeping air/contaminants out. | Equipment |
| **Attenuation** | How completely a yeast consumes sugar; higher = drier/lower FG. | Yeast Strains |
| **Back-sweetening** | Adding sugar/juice to a finished, **stabilized** wine for sweetness. | Additives / Recipes |
| **Bentonite** | Clay fining that removes proteins/haze. | Additives |
| **Bittersweet / bittersharp** | Cider-apple categories supplying tannin (and acid). | Fruit Profiles |
| **Bottle conditioning** | Carbonating in the bottle via a small priming-sugar refermentation. | SOP / Recipes |
| **Brix (°Bx)** | Sugar content as % by weight; ~1 °Bx ≈ 4 SG points. | Calculations / Fruit |
| **Bulk aging** | Aging in carboy/keg before bottling. | SOP |
| **Bung / stopper** | Rubber plug (often drilled for an airlock) sealing a vessel neck. | Equipment |
| **Campden tablet** | Pre-measured metabisulfite tablet (~50 ppm/gal); also dechlorinates water. | Additives / Sanitation |
| **Cap / punch-down** | Floating fruit layer in primary; pushed under 1–2×/day to extract and protect. | SOP |
| **Carboy** | Large narrow-necked vessel (glass or PET), ~3–6 gal, for secondary/aging. | Equipment |
| **Chaptalization** | Adding sugar to raise the must's gravity toward a target OG/ABV. | Calculations / Additives |
| **Clean vs sanitize vs sterilize** | Cleaning removes soil; sanitizing reduces microbes on a clean surface; home winemaking sanitizes, not sterilizes. | Sanitation |
| **Cold stabilization** | Chilling to drop excess tartaric acid/crystals. | Troubleshooting / Additives |
| **Contact time** | Minimum time a sanitizer must stay wetted on a surface to work. | Sanitation |
| **Degassing** | Stirring/agitating to drive off dissolved CO₂ before clearing/bottling. | SOP |
| **Demijohn / jug** | Smaller narrow-necked vessel (1–3 gal); 1-gal jug = standard small secondary. | Equipment |
| **Dextrose** | Corn sugar; ferments fully — used for priming sparkling cider. | Calculations / Recipes |
| **Dry / off-dry / sweet** | Residual-sugar styles: dry (none), off-dry (slight), sweet/dessert (high). | Recipes |
| **Final gravity (FG)** | Hydrometer reading at the end of fermentation (~0.995 wine, ~0.998–1.000 cider). | Calculations / SOP |
| **Fining / clarifier** | Agent (bentonite, Sparkolloid, kieselsol+chitosan, gelatin, isinglass) that drops haze. | Additives |
| **Flocculation** | How tightly yeast settles after fermentation; affects clearing. | Yeast Strains |
| **Free vs molecular SO₂** | Free = the protective sulfite reserve; molecular = the small active fraction (target ~0.8 ppm), pH-dependent. | Calculations / Additives |
| **Fusel alcohols** | Harsh/hot/solventy alcohols from too-warm fermentation. | Troubleshooting B6 |
| **Gross lees / fine lees** | Heavy early sediment / lighter later sediment. | SOP |
| **Headspace / topping up** | Air gap above the wine; minimized after fermentation by topping up. | SOP / Equipment |
| **H₂S** | Hydrogen sulfide; rotten-egg fault from nitrogen-starved yeast. | Troubleshooting B1 |
| **Hydrometer** | Float that reads specific gravity (OG/FG); needs temperature correction. | Equipment / Calculations |
| **Iodophor** | Iodine-based no-rinse sanitizer. | Sanitation |
| **Killer factor** | Trait (e.g. EC-1118) that suppresses wild yeast in the must. | Yeast Strains |
| **Lees** | Sediment of dead yeast and pulp left after fermentation. | SOP |
| **Must** | The unfermented mix of fruit, water, sugar, and additives. | SOP / Fruit |
| **Muselet** | Wire cage securing a champagne cork against pressure. | Equipment |
| **No-rinse** | A sanitizer that, at the correct dilution, is left on rather than rinsed. | Sanitation |
| **Original gravity (OG)** | Starting specific gravity of the must, before fermentation. | Calculations / Fruit |
| **Oxidation** | Oxygen damage: browning, sherry/nutty notes, lost aroma. | Troubleshooting B2 |
| **PBW** | Powdered Brewery Wash; oxygen-based cleaner (not a sanitizer). | Sanitation |
| **Pectic enzyme (pectinase)** | Breaks down pectin for juice yield, color, and to prevent haze. | Additives |
| **Pectin haze** | Permanent milky haze from undigested pectin; prevented pre-ferment. | Troubleshooting C1 |
| **pH** | Acidity scale driving flavor, stability, and sulfite dosing (wine ~3.2–3.6). | Calculations / Additives |
| **Pitching / pitch rate** | Adding yeast to the must; ~1 × 5 g sachet per ~5 gal. | Yeast Strains / Calculations |
| **Potential alcohol** | The ABV a must could reach from its sugar (≈ Brix × 0.55–0.59). | Calculations |
| **Pressing** | Separating liquid from fruit solids at the end of primary. | SOP / Equipment |
| **Priming sugar** | Measured sugar added at bottling to carbonate (~1 oz dextrose/gal). | Calculations / Recipes |
| **Racking** | Siphoning clear wine off the lees into a fresh vessel. | SOP / Equipment |
| **Refractometer** | Optical Brix meter; accurate only **before** fermentation. | Equipment / Calculations |
| **Rehydration** | Reviving dry yeast in ~104°F water (with rehydration nutrient) before pitching. | Yeast Strains |
| **Sorbate (potassium sorbate)** | Stabilizer that stops yeast reproducing; used **with** sulfite before sweetening. | Additives |
| **Specific gravity (SG)** | Density relative to water (1.000); read with a hydrometer. | Calculations |
| **Star San** | Acid-anionic no-rinse sanitizer; the home standard. | Sanitation |
| **Step-feeding** | Adding sugar in stages for high-ABV musts to avoid osmotic stress. | Calculations / Recipes |
| **Sugar break (1/3 break)** | The point ~1/3 of the sugar is consumed — the staged-nutrient cue. | Additives / SOP |
| **Sulfite (K-meta / SO₂)** | Potassium metabisulfite; antimicrobial + antioxidant (three distinct doses). | Additives / Sanitation |
| **Titratable acidity (TA)** | Total acid as % tartaric; table-wine target ~0.55–0.70%. | Calculations / Additives |
| **Tannin** | Compounds giving structure/astringency; added to low-tannin fruit. | Additives / Fruit |
| **Volumes of CO₂** | Carbonation measure; ~2.2–2.5 vol = moderate sparkle. | Calculations |
| **Wild yeast** | Uncontrolled environmental yeast causing off-flavors/haze. | Troubleshooting / Sanitation |
| **Wine thief** | Tube for drawing a clean sample to test. | Equipment |
| **YAN** | Yeast Assimilable Nitrogen; what the yeast can use — low in fruit musts. | Additives |
| **Yeast energizer** | Potent nutrient blend (DAP + vitamins + hulls) to wake/restart ferments. | Additives |
| **Yeast nutrient** | Nitrogen + micronutrients (DAP / complex) for a clean, complete ferment. | Additives |
