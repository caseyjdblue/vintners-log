# Prompt to Give Claude

I am building a fruit wine app. Use the attached UI reference image and the included design brief, design tokens, and sample data to build a polished mobile-first UI.

The app should feel like a soft artisan vineyard product: light, warm, modern, premium, and approachable. Keep the functionality serious and useful, but avoid a dark, heavy, enterprise, or generic admin-dashboard look.

Build the following screens/components first:

1. Home Dashboard
2. Batch Detail
3. Fruit Library
4. Recipe Detail
5. Inventory
6. Today’s Tasks
7. Shared components: cards, chips, metric cards, bottom navigation, primary/secondary buttons, progress ring, timeline, and chart container

Use the files:
- `CLAUDE_UI_BRIEF.md` for design direction and screen requirements
- `design_tokens.json` for colors, typography, spacing, radius, shadows, and component styling
- `sample_data.json` for realistic placeholder content
- `ui_reference_soft_artisan.png` as the visual target

Implementation priorities:
- Mobile-first responsive layout
- Clean reusable components
- Soft cream background
- Berry-purple primary actions
- White rounded cards with subtle borders and shadows
- Fruit/wine imagery areas with gentle overlays/fades
- Easy navigation across Home, Batches, Add, Recipes, and More
- Data should be clear but not visually intimidating

Do not copy the reference image pixel-for-pixel. Use it as a direction for mood, structure, spacing, and visual polish.
